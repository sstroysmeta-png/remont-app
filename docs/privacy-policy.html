Мы не продаём ваши данные третьим лицам и не используем их в рекламных целях. Приложение работает локально на вашем устройстве — ваши расчёты никуда не отправляются.

1. Кто мы

Приложение «М-Ремонт» (далее — «Приложение», «мы») — калькулятор стоимости ремонта, разработанный для помощи пользователям в оценке стоимости ремонтных работ. Контакт: m-remont1@bk.ru

2. Какие данные мы собираем

Приложение работает преимущественно без сбора персональных данных. Единственные данные, которые могут покидать ваше устройство:

  • Фотография плана квартиры — только если вы нажали кнопку «Сфотографировать план» или «Загрузить план» и дали разрешение камере/галерее. Изображение передаётся на наш защищённый сервер исключительно для автоматического распознавания помещений ИИ, после чего немедленно удаляется. Мы не храним ваши фотографии.
  • Обращение к форме обратной связи — если вы отправляете сообщение через кнопку «Связаться», передаётся только текст вашего сообщения и адрес электронной почты (если вы его указали).

Все остальные данные (площади комнат, выбранные материалы, результаты расчётов) хранятся исключительно локально на вашем устройстве и никуда не передаются.

3. Как мы используем данные

  • Фотография плана — только для однократного распознавания помещений с помощью ИИ (Claude от Anthropic). Изображение не сохраняется и не используется для обучения моделей.
  • Обращения через форму — для ответа на ваш вопрос или запрос.
  • Мы не профилируем пользователей, не показываем рекламу, не отслеживаем поведение.

4. Передача данных третьим лицам

Мы используем следующих поставщиков услуг:

  • Anthropic (Claude API) — для распознавания планов квартир по изображению. Политика конфиденциальности Anthropic: anthropic.com/privacy
  • Vercel — хостинг серверной части приложения. Политика: vercel.com/legal/privacy-policy
  • FormSubmit — обработка формы обратной связи. Ваш email и текст сообщения передаются этому сервису только при отправке формы.

Мы не передаём данные рекламным сетям, аналитическим брокерам или любым другим третьим лицам без вашего явного согласия.

5. Разрешения приложения

  • Камера — запрашивается только при нажатии кнопки «Сфотографировать план». Используется исключительно для съёмки плана квартиры.
  • Хранилище / Галерея — запрашивается только при нажатии кнопки «Загрузить план» для выбора изображения плана из вашей галереи.
  • Интернет — используется для распознавания плана (отправка изображения на сервер) и формы обратной связи.

Ни одно из перечисленных разрешений не используется в фоновом режиме.

6. Хранение данных

Все данные о вашей квартире, комнатах и расчётах хранятся только в памяти приложения на вашем устройстве. При закрытии приложения несохранённые данные удаляются. Мы не используем базы данных пользователей. Фотографии планов не сохраняются ни на нашем сервере, ни в облаке.

7. Дети

Приложение не предназначено для детей до 13 лет и не собирает их данные намеренно. Если вы считаете, что мы получили данные ребёнка, свяжитесь с нами: m-remont1@bk.ru

8. Ваши права

Вы вправе:

  • Запросить информацию о ваших данных, которые мы обрабатываем
  • Потребовать удаления ваших данных
  • Отозвать разрешения приложения в настройках устройства в любое время

Для любых запросов: m-remont1@bk.ru

9. Безопасность

Передача изображений на сервер осуществляется по зашифрованному соединению HTTPS. API-ключи хранятся исключительно на сервере в защищённых переменных окружения и недоступны из браузера или приложения.

10. Изменения политики

О существенных изменениях мы уведомим через обновление приложения. Актуальная версия политики всегда доступна по этому адресу.

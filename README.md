# М-Ремонт — Калькулятор ремонта

Точный расчёт стоимости ремонта по реальным ценам строительного рынка России.

## Возможности

- 📐 Расчёт всех видов ремонтных работ и материалов
- 🤖 ИИ-распознавание плана квартиры по фото
- 🏙 8 городов России с актуальными ценами (2026)
- 💰 Три класса ремонта: Эконом, Комфорт, Премиум
- 📄 Экспорт сметы в PDF

## Технологии

- React 18
- Vercel (хостинг + Serverless API)
- Claude API (распознавание планов)
- Capacitor (мобильная обёртка)

## Структура

```
api/              ← Serverless-функции Vercel
  recognize-plan.js  ← ИИ-распознавание плана
docs/             ← GitHub Pages (политика конфиденциальности)
src/              ← React-приложение
public/           ← Статические файлы
```

## Деплой

Проект автоматически деплоится на Vercel при push в ветку `main`.

# ИНСТРУКЦИЯ: Как опубликовать М-Ремонт в Google Play
### Написано максимально просто — для человека, который делает это впервые

---

```
ШАГ 1 → Скачать и установить нужные программы (1 раз)

```

## ШАГ 1: УСТАНОВИТЬ ПРОГРАММЫ

### 1.1 Установить Git
Git — это программа для загрузки кода на GitHub.

1. Зайди на сайт: **https://git-scm.com/downloads**
2. Нажми **Download for Windows** (или Mac, если у тебя Mac)
3. Запусти скачанный файл, жми **Next** на всех экранах, **Install**
4. Готово. Проверь: открой **Командную строку** (нажми Win+R, введи `cmd`, Enter)
   и введи: `git --version`
   Должно показать что-то вроде: `git version 2.43.0`

### 1.2 Установить Node.js
Node.js — нужен для сборки приложения.

1. Зайди на: **https://nodejs.org**
2. Нажми большую зелёную кнопку **LTS** (это стабильная версия)
3. Установи, жми Next везде
4. Проверь в командной строке: `node --version`
   Должно показать: `v20.x.x` или выше

### 1.3 Установить Java JDK
Нужен для создания ключа подписи.

1. Зайди на: **https://adoptium.net**
2. Нажми **Latest LTS Release** — скачается установщик
3. Установи, жми Next везде
4. Проверь: `java -version`

5. Ты увидишь страницу с инструкциями. Оставь её открытой.

## ШАГ 3: ЗАГРУЗИТЬ КОД НА GITHUB

### 3.1 Открыть командную строку в нужной папке

**На Windows:**
1. Открой папку **remont-app** в Проводнике
2. В адресной строке проводника (вверху, где написан путь) кликни один раз
3. Напечатай `cmd` и нажми Enter
4. Откроется чёрное окно — командная строка в нужной папке

**На Mac:**
1. Открой Terminal (Finder → Программы → Утилиты → Terminal)
2. Напечатай `cd ` (с пробелом), потом перетащи папку remont-app в окно Terminal
3. Нажми Enter

### 3.2 Ввести команды по одной

Копируй и вставляй каждую строку в командную строку, нажимай Enter после каждой:

```
git init
```
```
git add .
```
```
git commit -m "Первый коммит — М-Ремонт v1.0"
```
```
git branch -M main
```

Теперь самая важная команда — замени `ВАШ_ЛОГИН` на твой логин GitHub:
```
git remote add origin https://github.com/ВАШ_ЛОГИН/remont-app.git
```

Пример (если твой логин `mremont2025`):
```
git remote add origin https://github.com/mremont2025/remont-app.git
```

Загружаем код:
```
git push -u origin main
```

Появится запрос логина/пароля GitHub → введи свои данные.

### 3.3 Проверить результат
Зайди на https://github.com/ВАШ_ЛОГИН/remont-app — ты должен видеть все файлы проекта.
Если видишь — всё хорошо! ✅

6. Появится ссылка вида: `https://ВАШ_ЛОГИН.github.io/remont-app/`

**Твоя ссылка на политику конфиденциальности:**
```

```

👉 Сохрани эту ссылку — она нужна для Google Play Console!

## ШАГ 5: ПОДКЛЮЧИТЬ VERCEL

> Vercel — это облачный сервер, где будет работать функция распознавания планов

### 5.1 Войти в Vercel и создать НОВЫЙ проект

1. Зайди на **https://vercel.com** и войди в свой аккаунт
2. Нажми кнопку **Add New...** → **Project**
3. Найди в списке репозиторий `remont-app` (только что созданный)
4. Нажми **Import**

### 5.2 Настроить проект

На экране настройки:
- **Project Name:** `remont-app` (или любое другое название)
- **Framework Preset:** выбери **Create React App**
- **Root Directory:** оставь как есть (точка `.`)
- **Build Command:** `npm run build` (должно быть уже)
- **Output Directory:** `build`

Не нажимай Deploy ещё! Сначала ШАГ 6.

## ШАГ 6: ДОБАВИТЬ API-КЛЮЧ В VERCEL

> Это самый важный шаг — без него распознавание планов не работает

### 6.1 Получить API-ключ (если ещё нет)

1. Зайди на **https://console.anthropic.com**
2. Войди или зарегистрируйся
3. Нажми **API Keys** в левом меню
4. Нажми **Create Key**
5. Дай название, например `remont-app`
6. Скопируй ключ — он начинается с `sk-ant-...`
   ⚠️ Скопируй сразу! Потом не покажут.

### 6.2 Добавить ключ в Vercel

На экране настройки проекта Vercel (или после создания — в Settings):

1. Найди раздел **Environment Variables**
2. Нажми **Add**
3. Заполни:
   - **Name:** `ANTHROPIC_API_KEY`
   - **Value:** вставь свой ключ (sk-ant-...)
   - Environment: выбери все три галочки (Production, Preview, Development)
4. Нажми **Save**

### 6.3 Запустить деплой

Нажми **Deploy** (большая синяя кнопка).

Подожди 2–5 минут. Если всё хорошо — увидишь зелёную галочку и ссылку вида:
```
https://remont-app-хххх.vercel.app
```

👉 Это и есть адрес твоего сервера! Сохрани его.

## ШАГ 7: СОЗДАТЬ КЛЮЧ ПОДПИСИ (KEYSTORE)

> Keystore — это как паспорт приложения. Без него нельзя обновлять приложение в Google Play.
> ⚠️ Создаётся ОДИН РАЗ. Если потеряешь — приложение нельзя будет обновить!

### 7.1 Запустить скрипт

В командной строке, в папке remont-app:

**Windows:**
```
cd keystore-info
bash generate-keystore.sh
```

Если bash не работает — используй Git Bash (установился вместе с Git):
правой кнопкой по папке → **Git Bash Here**, потом:
```
bash generate-keystore.sh
```

**Mac:**
```
cd keystore-info
bash generate-keystore.sh
```

### 7.2 Ответить на вопросы

Скрипт задаст вопросы. Можно вводить любые данные, главное — запомни пароль!

```
Enter keystore password: [придумай пароль, минимум 6 символов]
Re-enter new password: [повтори пароль]
What is your first and last name? Remont App
What is the name of your organizational unit? IT
What is the name of your organization? M-Remont
What is the name of your City or Locality? Saint Petersburg
What is the name of your State or Province? Leningradskaya
What is the two-letter country code? RU
Is CN=Remont App, ... correct? yes
```

После этого создастся файл `remont-app-release.keystore`.

### 7.3 Сохранить данные

Создай файл `keystore-info/МОИ-ДАННЫЕ.txt` (НЕ загружай в GitHub!):
```
Файл: remont-app-release.keystore
Alias: remont-key
Пароль keystore: [твой пароль]
Пароль ключа: [твой пароль]
Дата создания: [сегодняшняя дата]
```

Скопируй файл `.keystore` ещё в:
- Флешку
- Облако (Google Drive / Яндекс Диск)
- Любое надёжное место

## ШАГ 8: СОБРАТЬ ПРИЛОЖЕНИЕ (APK/AAB)

Для Google Play нужен формат **AAB** (Android App Bundle).

### 8.1 Установить Capacitor

Capacitor превращает веб-приложение в мобильное.

В командной строке в папке remont-app:
```
npm install
npm install @capacitor/core @capacitor/cli @capacitor/android
npx cap init "М-Ремонт" "ru.mremont.app" --web-dir build
npm run build
npx cap add android
npx cap sync
```

### 8.2 Открыть Android Studio

1. Скачай Android Studio: **https://developer.android.com/studio**
2. Установи (жми Next везде, займёт ~20 минут)
3. После установки: в командной строке введи:
   ```
   npx cap open android
   ```
4. Android Studio откроется с проектом

### 8.3 Настроить подпись в Android Studio

1. В Android Studio нажми **Build** (верхнее меню)
2. Выбери **Generate Signed Bundle / APK...**
3. Выбери **Android App Bundle** → Next
4. В поле **Key store path** нажми **Choose existing...**
   Найди файл `remont-app-release.keystore`
5. Введи пароли (те что создавал)
6. Key alias: `remont-key`
7. Нажми **Next** → выбери **release** → **Finish**

Файл AAB создастся в папке:
```
android/app/release/app-release.aab
```

## ШАГ 9: ЗАГРУЗИТЬ В GOOGLE PLAY CONSOLE

### 9.1 Создать аккаунт разработчика (если нет)

1. Зайди на **https://play.google.com/console**
2. Нажми **Начать** → оплати $25 (один раз навсегда)
3. Заполни данные профиля

### 9.2 Создать новое приложение

1. Нажми **Создать приложение**
2. Заполни:
   - Язык по умолчанию: **Русский**
   - Название: **М-Ремонт: Калькулятор ремонта**
   - Приложение или игра: **Приложение**
   - Бесплатное или платное: **Бесплатное**
3. Согласись с условиями → **Создать приложение**

### 9.3 Заполнить информацию о приложении

В левом меню найди **Сведения о магазине** → **Основные сведения о магазине**:

- **Краткое описание:** текст из файла `keystore-info/google-play-listing.md`
- **Полное описание:** текст оттуда же
- **Значки:** загрузи `icon-512.png` (лежит в папке `public/`)
- **Скриншоты телефона:** загрузи скриншоты из нашего архива (минимум 2, лучше 5-6)
  Размер должен быть от 320px до 3840px по каждой стороне

### 9.4 Добавить политику конфиденциальности

В меню: **Политика конфиденциальности**
Вставь ссылку:
```
https://ВАШ_ЛОГИН.github.io/remont-app/privacy-policy.html
```

### 9.5 Заполнить рейтинг контента

В меню: **Рейтинг контента** → Заполни анкету → категория **Утилиты**
Отвечай "Нет" на все вопросы про насилие/секс/наркотики.

### 9.6 Загрузить AAB-файл

1. В левом меню: **Тестирование → Внутреннее тестирование**
2. Нажми **Создать новый выпуск**
3. Нажми **Загрузить** → выбери файл `app-release.aab`
4. Дождись обработки (1–3 минуты)
5. В поле "Примечания к выпуску": "Первый релиз"
6. Нажми **Сохранить** → **Просмотреть выпуск** → **Опубликовать**

### 9.7 Перейти в открытый доступ

После тестирования:
1. **Производство → Управление выпуском → Создать выпуск**
2. Загрузи тот же AAB
3. Нажми **Опубликовать**

Модерация занимает от нескольких часов до 7 дней.

## ВОЗМОЖНЫЕ ПРОБЛЕМЫ И РЕШЕНИЯ

### ❌ "git не является внутренней командой"
→ Перезапусти командную строку после установки Git

### ❌ "npm: command not found"
→ Перезапусти командную строку после установки Node.js

### ❌ Vercel показывает ошибку при деплое
→ Зайди в Vercel → твой проект → вкладка **Deployments** → кликни на красный деплой → смотри логи ошибок

### ❌ Распознавание плана не работает
→ Проверь переменную `ANTHROPIC_API_KEY` в настройках Vercel:
  Settings → Environment Variables → убедись что ключ правильный

### ❌ GitHub push просит логин/пароль и не принимает
→ Нужен Personal Access Token вместо пароля:
  GitHub → Settings → Developer settings → Personal access tokens → Generate new token
  Выдай права: repo, workflow
  Используй этот токен вместо пароля

### ❌ Android Studio не открывается / ошибки сборки
→ В Android Studio: Tools → SDK Manager → убедись что установлен Android SDK 33+
